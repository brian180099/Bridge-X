## 명확한 지원 범위
브라우저 저장은 팀 공동 저장이 아니다. 검토 체크는 로그인한 팀원의 승인이 아니다.
음성은 파일당 4MB까지 처리한다. 마이크 녹음은 주변 소리를 수집하며 온라인 회의 상대방 오디오를 자동 수집하지 않는다.
화자 자동 분리와 음성 타임스탬프는 미지원이다. 전사 후 사용자가 이름을 붙일 수 있다.
AI 우선순위와 완료 기준은 제안이다. 불명확한 담당자는 미정, 상대 날짜는 빈 날짜로 남긴다.
ICS와 Markdown은 파일 내보내기이며 OAuth 연결·자동 동기화가 아니다.
문화 설명은 입력 맥락에 기반한 가능성으로만 다룬다.
기존 텍스트 요청 분석 코드는 보존했지만 기본 진입 화면은 회의 작업 공간으로 변경했다.

## 후속 개발 우선순위
1. 긴 음성 파일을 위한 비공개 객체 저장소, 분할 처리, 비동기 작업 큐.
2. 화자 자동 구분과 참여자 매핑, 타임스탬프 기반 재생.
3. 팀 공동 DB, 접근 권한, 팀원별 수정·확인 기록.
4. Notion OAuth와 데이터베이스 속성 매핑, 중복 생성 방지.
5. Google Calendar OAuth, 이벤트 식별자 저장, 수정·삭제 동기화.
6. 회의 간 의존성·우선순위 관리 및 팀 용어 사전.
7. 공개 AI API 비용 제한 및 공유 서비스 운영 인증.

## 수동 확인 경로
홈 → 새 회의 → 예시 입력 → 회의 분석 → 직무 필터 → 업무 수정 → 내 검토 완료 → 날짜 지정 → ICS / Markdown.
마이크는 사용자 권한 허용 후 녹음 종료 → 재생 → 전사 내용 추가 → 전사 검토 → 분석.

## 검증 결과
- TypeScript 및 Vite 빌드 통과.
- 입력 검증, ICS 이스케이프·월 경계·미검토 제외, Markdown 내보내기 등 자동 테스트 통과.
- 실제 OpenAI 회의 분석: 예시에서 업무 3개, 확인 표현 1개, 용어 2개 생성 확인.
- 합성 음성으로 실제 전사 API 200 응답 및 발화 내용 일치 확인.
- 브라우저에서 날짜 수정·개인 검토 체크 후 새로고침 복원 확인.
- 실제 마이크 권한·녹음은 사용자 기기에서 추가 확인 필요.
