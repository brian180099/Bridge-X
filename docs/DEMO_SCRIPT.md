# Bridge X 3분 발표·데모

## 0:00–0:25 · 문제

“회의록이 있어도 실행은 자주 어긋납니다. ‘우선 적용하고 빠르게 확인하자’는 말에서 PM, 개발자, 운영자가 생각하는 담당자와 완료 조건이 다르기 때문입니다. 글로벌 팀에서는 번역 뒤에도 직무 용어와 문화적 맥락 차이가 남습니다.”

홈 화면의 한 줄 설명과 최근 회의 영역을 보여줍니다.

## 0:25–0:55 · 회의 입력과 전사

`새 회의`를 누르고 회의명과 참석 직무를 보여줍니다.

“Bridge X에서는 브라우저로 바로 녹음하거나 음성 파일을 올릴 수 있습니다. 녹음 동의를 확인한 뒤 AI가 전사하고, 사용자는 분석 전에 전사문을 직접 수정할 수 있습니다.”

발표 안정성을 위해 실제 현장 녹음 대신 미리 준비한 짧은 음성이나 전사문을 사용합니다.

## 0:55–1:25 · AI 분석

`회의 분석`을 누릅니다.

“AI는 회의를 단순 요약하지 않습니다. 결정사항과 함께 담당 직무, 우선순위, 기한, 선행 조건, 완료 기준이 있는 실행 항목을 만듭니다. 기한이나 담당자가 원문에 없다면 임의로 확정하지 않고 검토가 필요한 상태로 남깁니다.”

## 1:25–2:05 · 직무별 할 일

`할 일` 탭에서 한 카드를 엽니다.

“각 항목에서 담당자, 날짜, 우선순위, 완료 조건을 수정할 수 있습니다. AI가 만든 초안과 사람이 확인한 항목은 상태가 다르게 표시됩니다. 수정 후 `검토 완료`를 눌러 팀이 실제로 합의한 실행 항목으로 바꿉니다.”

원문 근거 문장을 함께 가리킵니다.

## 2:05–2:35 · 오해 가능성과 용어

`확인할 표현`과 `용어 가이드` 탭을 차례로 엽니다.

“Bridge X는 ‘빠르게’, ‘완료’, ‘우선’처럼 직무마다 다르게 해석될 표현을 실제 발언과 함께 보여줍니다. 문화 차이를 단정하지 않고, 왜 확인해야 하는지와 어떤 질문을 할지 제안합니다. 도메인 용어도 회의 맥락에 맞춰 설명합니다.”

## 2:35–2:50 · 후속 작업 연결

“검토한 결과는 Notion에 가져갈 Markdown과 캘린더에 넣을 ICS 파일로 내보낼 수 있습니다. 현재는 파일 내보내기 방식이며, 직접 OAuth 연동은 다음 단계입니다.”

## 2:50–3:00 · 결론

“Bridge X는 회의를 기록하는 도구가 아니라, 서로 다른 직무와 문화권의 팀이 같은 회의를 같은 방향으로 실행하도록 돕는 협업 운영 도구입니다. 회의가 끝나는 순간, 말을 실행 가능한 합의로 바꿉니다.”

## 발표 전 체크

- 배포 URL과 `/api/health`가 열리는지 확인합니다.
- 새 회의 생성부터 결과 화면까지 한 번 리허설합니다.
- 30초 이내의 짧은 테스트 음성을 준비합니다.
- 실제 개인정보·회사 비밀·타인의 음성을 사용하지 않습니다.
- 브라우저 배율은 90%, 화면 폭은 1280px 이상을 권장합니다.
- 네트워크 실패에 대비해 분석 완료된 회의 하나를 브라우저에 미리 저장합니다.
