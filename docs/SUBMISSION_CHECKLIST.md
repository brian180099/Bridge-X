## 과장하면 안 되는 표현

- “Notion·Google Calendar와 연동된다” 대신 **“Markdown·ICS 파일로 내보낼 수 있다”**라고 작성합니다.
- “문화 차이를 판별한다” 대신 **“오해 가능성과 확인 질문을 제안한다”**라고 작성합니다.
- “팀 데이터가 클라우드에 저장된다” 대신 **“현재 브라우저에 저장되는 프로토타입”**이라고 작성합니다.
- “AI가 업무를 확정한다” 대신 **“AI가 초안을 만들고 사용자가 검토·확정한다”**라고 작성합니다.

## 제출 직전 5분 점검

1. 시크릿 창에서 서비스 URL을 엽니다.
2. `새 회의` → 전사문 입력 → `회의 분석`을 실행합니다.
3. 결과 탭과 할 일 편집·검토 완료가 동작하는지 봅니다.
4. Markdown·ICS 파일을 각각 내려받습니다.
5. 대회 폼 링크를 다시 열고 `제출 완료` 상태를 확인합니다.
