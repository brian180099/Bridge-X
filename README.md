# Bridge-X

서로 다른 전문 AI 에이전트 사이에서 **업무 맥락이 잘못 전달되지 않도록 만드는 협업 오케스트레이션 플랫폼**입니다.

> 우리는 에이전트가 더 많이 대화하게 만들지 않습니다.
>
> 에이전트 사이에서 일이 잘못 전달되지 않게 만듭니다.

## Repository structure

- `frontend/` — 워크룸, 에이전트 진행 상황, 핸드오프·충돌·승인 UI
- `backend/` — 오케스트레이션, 에이전트 연결, 핸드오프 검증, 실행 이력 API
- `docs/PROJECT_BRIEF.md` — 문제 정의, 차별점, MVP 범위와 검증 과제

## First product: AI Product War Room

사용자가 아이디어나 업무 목표를 입력하면 리서치·기획·UX·개발·리스크·검증 역할의 에이전트가 병렬로 검토합니다. Bridge-X는 결과를 단순 연결하지 않고 `Context Handoff` 형식으로 정규화해 다음을 보여줍니다.

- 목적과 완료 조건
- 근거와 출처
- 사실과 가정의 구분
- 제약 조건과 누락된 전제
- 역할 간 충돌
- 사람이 결정해야 할 항목
- 최종 `Go / Revise / Stop` 제안

## Product direction

BridgeNote가 사람 사이의 언어·문화적 맥락 손실을 다뤘다면, Bridge-X는 사람과 AI 및 AI 에이전트 사이의 **업무 맥락 손실**을 다룹니다. 범용 에이전트 빌더가 아니라, 에이전트 간 전달 품질과 검증 가능성에 집중합니다.

현재 단계는 문제 정의 및 MVP 설계입니다. 기술 선택은 확정 사항과 제안 사항을 구분해 진행합니다.
